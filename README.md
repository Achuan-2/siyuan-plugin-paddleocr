# PaddleOCR 图片识别

使用 PaddleOCR PP-OCRv6 ONNX 模型，在思源界面所在设备上识别图片文字。可在插件设置中选择 tiny 或 small（默认 small）；插件包不包含检测或识别模型，用户可在设置中下载。识别过程无需把图片发往第三方服务。

## 使用

* 在思源正文里的普通资源图片上打开图片菜单：桌面端选择 OCR - PaddleOCR，移动端直接选择 PaddleOCR。
* 通过命令面板打开识别窗口，选择本机图片后自动识别。

弹窗左侧显示原图，右侧显示可编辑的识别文字；可在图片上划选多行识别文字，按 Ctrl+C 复制。通过图片菜单识别时，如果图片尚无 OCR 文字，会自动将非空识别结果保存到思源，供搜索使用；已有 OCR 文字时保留原内容。检查或修改右侧结果后，也可选择“保存到思源 OCR”手动保存。

识别窗口可选择“自动”“去除换行符”“原本”三种排版方式。自动排版结合识别文字和图片中的文字框位置，合并连续正文，保留列表、短标签和段落间的换行；“原本”保留识别引擎返回的逐行结果。切换排版时，各选项下的手动修改会分别保留；复制和保存使用当前显示的文字。

识别弹窗中的检测阈值和识别阈值默认取全局设置，可临时调整为 0–1 之间的数值，再点击“重新识别”应用。调整仅对当前弹窗有效，不影响全局设置或粘贴图片自动识别；点击“使用全局设置”可恢复当前全局阈值。

设置中的“高级运行设置”默认折叠，修改后自动保存，并在下次识别时生效。可调整检测置信度阈值（默认 0.7）和识别置信度阈值（默认 0.6），取值范围为 0–1；调低可以保留更多不确定文字，调高可以减少误检。默认阈值用于减少截图图标、箭头被误识别成生僻字，模糊、很小的真实文字也可能被过滤。

检测图像最大边长可选择“模型默认”或 640、960、1280、1920 像素，默认 960；显式选择边长时，大图会按最长边上限缩小，小图不会因此放大。较小通常更省资源，较大有利于保留小字细节。文字识别批量大小可选 1、4、8、16 行，默认 8；较小更省内存，较大可能加快多行识别。已有的自定义设置会保留，点击“恢复默认”可应用新的默认设置。

推理后端可选择“自动”（默认）、“WebGPU 优先”或“WASM（CPU）”。自动模式优先尝试 WebGPU；WebGPU 不可用、初始化失败或 GPU 推理失败时回退 WASM。更改后端后，下次识别会重新加载引擎。WASM 线程数由运行环境自动选择。识别完成后会显示总耗时、检测和文字识别各自的耗时及实际使用的后端；WebGPU 的可用性与加速效果取决于思源宿主、设备 GPU 和驱动。

默认开启“粘贴图片后自动识别”。在编辑器中粘贴新图片并成功上传到普通资源目录后，插件会按自动排版识别并保存 OCR 文字；已有 OCR 文字时跳过。可在插件设置中关闭此功能。插件仅在思源界面打开时处理粘贴，不处理同步、导入或内核后台写入，也不覆盖内核的后台 OCR。移动端的运行速度与内存使用取决于设备 WebView；鸿蒙端仍需真机验证。
